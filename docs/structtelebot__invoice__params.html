Detailed Description

Description of an invoice, shared by telebot_send_invoice() and telebot_create_invoice_link().

Zero-initialise it and set what you need; title, description, payload, currency and prices are required. For payments in Telegram Stars use currency "XTR" and leave provider_token NULL.
