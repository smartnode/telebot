Detailed Description

A file to send (Bot API "InputFile or String").

Build one with telebot_input_file_remote(), telebot_input_file_path() or telebot_input_file_memory(), or in C with the TELEBOT_FILE_REMOTE(), TELEBOT_FILE_PATH() and TELEBOT_FILE_MEMORY() macros. All pointers are borrowed: they must stay valid until the call that uses the file returns.
