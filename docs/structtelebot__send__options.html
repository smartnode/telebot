Detailed Description

Options shared by every method that sends a message.

Pass NULL wherever a function takes const telebot_send_options_t * to use Telegram's defaults. Zero-initialise the struct and set only what you need:

telebot_send_options_t opts = {0};
opts.reply_to_message_id = msg->message_id;
opts.reply_markup = "{\"inline_keyboard\":[[{\"text\":\"OK\",\"callback_data\":\"ok\"}]]}";
telebot_send_message(bot, chat_id, "Done", NULL, false, &opts);
